AED I — Vetores e Ordenação

Descrição do projeto

Este projeto foi desenvolvido como parte dos estudos de Algoritmos e Estruturas de Dados I (AED I), no curso de Ciência da Computação.

O programa permite que o usuário informe cinco números inteiros, armazena os valores em um vetor e os organiza em ordem crescente utilizando o algoritmo de ordenação Bubble Sort.

Objetivo

Praticar os conceitos de vetores, estruturas de repetição, entrada e saída de dados e algoritmos de ordenação na linguagem C.

Linguagem utilizada

* Linguagem C

Como executar

1. Tenha um compilador de C instalado, como o GCC.
2. Baixe o arquivo main.c deste repositório.
3. Abra o terminal na pasta do arquivo.
4. Compile o programa com o comando:
    gcc main.c -o programa
5. Execute o programa:
    ./programa

No Windows, após compilar, execute programa.exe.

Conteúdos estudados

* Vetores
* Estruturas de repetição
* Manipulação de números inteiros
* Algoritmo Bubble Sort
* Ordenação crescente
